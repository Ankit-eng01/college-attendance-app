Privacy & Security Policy
1. No Advertising or Analytics Trackers Attendify ships without analytics SDKs, advertising pixels, or third-party cookies. We do not sell personal or academic data.
2. Local-First Storage & Optional Cloud Backup Attendance records, subjects, and calendar entries are stored in this device's browser storage and the app works offline. While cloud sync is enabled (the default), your attendance data, account email (if signed in), and a compact device label (device type, browser, OS, screen size) are sent over HTTPS to the Attendify sync API so you can restore on another device. Guest records use the same backup flow and can be restored with the sync code shown in Settings; create an account for email-based recovery.
3. XSS Protection & Strict Content Security Policy (CSP) All rendered user inputs undergo strict character escaping. A Content Security Policy restricts scripts to first-party sources and blocks unauthorized payloads and cross-site scripting.
4. Verified JSON Backups & Schema Validation Imported backup files are checked by an in-memory schema validator that verifies object bounds, property types, and value limits before applying state changes.
5. Account Security Passwords are hashed server-side with scrypt and a per-account salt. Sync tokens are hashed for verification and encrypted at rest. No passwords, API keys, or secret tokens are embedded in the frontend code.
6. Your Data Rights & Deletion You can export a CSV or JSON copy at any time. Clearing data removes local records and can also delete your cloud backup from the server. Guest records remain local unless you choose to create an account and sync.
