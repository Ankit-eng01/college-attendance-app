🛡️ Privacy & Security Policy
1. Zero Telemetry & No Data Collection Attendify does not collect, log, transmit, or sell your personal or academic records. There are no advertising trackers, analytics SDKs, or third-party cookies.
2. Local-First Device Storage All attendance logs, calculations, and subject lists are stored exclusively on your local device via sandboxed HTML5 LocalStorage. The application functions 100% offline.
3. XSS Protection & Strict Content Security Policy (CSP) All rendered user inputs undergo strict character escaping. The app enforces a strict Content Security Policy to stop unauthorized scripts, external payloads, and cross-site scripting (XSS).
4. Verified JSON Backups & Schema Validation Imported backup files are checked by an in-memory schema validator that verifies object bounds, property types, and value limits before applying state changes.
5. Zero Plaintext Passwords or Secret Keys Attendify does not store API credentials, tokens, or passwords in client code. If optional multi-device sync accounts are introduced, they will enforce OAuth 2.0 PKCE and end-to-end encryption.
6. Student Data Rights & Total Deletion You have full sovereignty over your academic information. You can export a CSV or JSON copy anytime, or execute a permanent factory reset with a single tap.
